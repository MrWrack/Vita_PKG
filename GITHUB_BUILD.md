# GitHub build

The real GitHub Actions workflow is already included at:

`.github/workflows/build.yml`

A visible duplicate is also included at:

`github-build.yml`

If you upload files manually through GitHub's web UI, make sure the real file ends up at:

`.github/workflows/build.yml`

Then open **Actions -> Build MrWrack PKG Converter -> Run workflow**.

Successful builds upload:

`MrWrack-PKG-Converter-v1.0-alpha.vpk`

as a GitHub Actions artifact.
