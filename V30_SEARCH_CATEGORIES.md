# v3.0 Search Categories

Adds a separate Search category to the home screen.

Search -> Homebrew
- scans VPK and MRW-PKG files in the configured package folders
- also lists installed non-PCS applications from ux0:/app

Search -> Games
- scans installed Vita titles in ux0:/app
- PCS* title IDs are treated as game titles

This is a local scanner only. It does not download commercial games.
