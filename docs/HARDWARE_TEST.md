# Vita hardware test

1. Install v1.5 VPK.
2. Start MrWrack PKG Converter.
3. Confirm the green MRWRACK PKG CONVERTER header appears.
4. Put one test MRW-PKG in `ux0:/data/MrWrackPKG/pkg/`.
5. Press Triangle to rescan.
6. Select the MRW-PKG and press X.
7. If installation fails, photograph the complete `Result: ... / 0x........` line.

Do not test commercial/DRM packages. This test path is for homebrew MRW-PKG files.
